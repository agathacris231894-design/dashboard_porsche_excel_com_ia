## 📌 Sobre o projeto

Dashboard interativa desenvolvida para explorar uma base fictícia de vendas de veículos Porsche. O projeto transforma registros em indicadores, gráficos e tabelas para facilitar a análise dos modelos, valores registrados, formas de pagamento, localização e status.

A interface oferece filtros interativos e dois temas visuais: **Porsche Brasil** e **Power BI**.

## 📊 Perguntas de negócio

As análises foram definidas para investigar a distribuição dos registros e identificar padrões relevantes na base.

| Pergunta | Objetivo |
|---|---|
| Quais modelos aparecem com maior frequência? | Identificar os modelos mais registrados. |
| Quais modelos apresentam os maiores valores? | Comparar os valores registrados por modelo. |
| Quais modelos predominam em cada cidade? | Explorar preferências por localidade dentro da base. |
| Quais anos de modelo são mais frequentes? | Analisar a distribuição dos veículos registrados. |
| Onde os registros estão concentrados? | Investigar a distribuição por estado. |
| Quais formas de pagamento movimentam os maiores valores? | Comparar os valores por método de pagamento. |
| Como os registros e valores se distribuem por status? | Analisar cada situação sem presumir que todos os registros sejam vendas concluídas. |

## 🎨 Funcionalidades

- Filtros por modelo, ano do veículo, cidade e forma de pagamento.
- Indicadores principais e gráficos comparativos.
- Análise de registros e valores por status.
- Distribuição geográfica e análise por cidade.
- Tabelas com os dados detalhados e a validação das datas.
- Alternância entre os temas Porsche Brasil e Power BI.
- Formatação monetária em reais (BRL).

## 🤖 Desenvolvimento com inteligência artificial

O ChatGPT foi utilizado como apoio à criação, revisão e evolução da dashboard. O desenvolvimento envolveu ajustes visuais, gráficos, filtros, tabelas e verificações de consistência dos dados.

### Prompt inicial

O prompt original foi elaborado para gerar uma dashboard em HTML utilizando o recurso Canvas:

### 📝 Prompt inicial

> Utilizando o recurso **Canvas**, renderize uma dashboard em HTML ao lado, considerando os seguintes requisitos:

#### 🔎 Filtros
- Modelo da Porsche;
- Model Year (ano do modelo);
- City (cidade);
- Pay Method (forma de pagamento).

#### 📊 Perguntas de negócio
- Quais são os principais modelos vendidos por cidade?
- Qual ano de modelo apresenta maior frequência em determinado período?
- Quais modelos são mais populares em cada cidade, considerando os dados disponíveis?
- Qual é a relação entre os modelos e o faturamento? Quais modelos da Porsche apresentam os maiores valores registrados?
- Em quais estados e cidades os registros de vendas estão concentrados?
- Quais métodos de pagamento são mais utilizados e quais valores movimentam?

#### 🎨 Requisitos de UI/UX
- Utilizar o [site oficial da Porsche Brasil](https://www.porsche.com/brazil/pt/) como referência visual.
- Desenvolver uma interface elegante, refinada e alinhada à identidade visual da marca.
- Criar também uma versão alternativa inspirada nos componentes visuais do Power BI.

### Evolução até a versão final

O projeto evoluiu com a inclusão de análises por status, tabelas detalhadas, formatação monetária, identificação de datas inconsistentes e aprimoramentos na organização do HTML, CSS e JavaScript.

Essas mudanças buscaram ampliar a capacidade de análise e melhorar a clareza e a confiabilidade das informações apresentadas.

## 🧹 Tratamento e preparação dos dados

A base fictícia passou por uma revisão de consistência antes de ser utilizada na dashboard.

- **Datas inválidas:** quatro datas impossíveis foram substituídas por datas fictícias plausíveis.
- **Padronização:** três datas originalmente no formato americano foram convertidas para o padrão brasileiro.
- **Datas ambíguas:** casos sem interpretação segura foram sinalizados para revisão.
- **Valores monetários:** apresentados em BRL, conforme definido para a base.
- **Status e registros:** preservados para evitar exclusões indevidas e permitir análises separadas por situação.

> Os ajustes de datas são intervenções em uma base fictícia para fins educacionais. Os valores e registros não representam necessariamente transações reais.
